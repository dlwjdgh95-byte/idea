# idea

생각을 탐색·검증하고 맥락을 쌓아 심화하는 차세대 검색엔진 프로젝트입니다.
설계 문서: [맥락형 검색엔진 프로토타입 설계](https://claude.ai/artifact/C5iRM7y16L1PWJR2wxhEe4)

## idea-council

아이디어를 전개하는 LLM 카운슬입니다. 구조는 Andrej Karpathy의
[llm-council](https://github.com/karpathy/llm-council)(독립 답변 → 익명 상호 순위 → 의장 종합)을 따르고,
LLM 판정자의 알려진 약점을 막는 장치와 사실 검증 게이트를 더했습니다.

| 단계 | 하는 일 | 원본과 다른 점 |
| --- | --- | --- |
| 1. 독립 전개 | 위원 4명이 서로의 답을 보지 않고 답함 | 위원마다 역할(확장자·비판자·실행가·연결자)을 주고, 실행마다 역할을 섞음 |
| 2. 익명 상호 검토 | 다른 위원의 답을 A, B, C로 가려 비판하고 순위를 매김 | 검토자마다 제시 순서를 섞고, 자기 답은 아예 보여 주지 않음. 정확성·근거·참신성·실행 가능성 점수와 의심 주장을 함께 받음 |
| 2.5. 검증 게이트 | 의심받은 주장과 핵심 주장을 웹 검색으로 검증 | 원본에 없음. 확신도는 모델이 아니라 규칙(`confidence.py`)이 계산 |
| 3. 의장 종합 | 결론, 합의, 쟁점·소수 의견, 검증된 주장, 다음 질문, 연결 후보 | 검증 결과표의 확신도를 그대로 쓰고, 80% 미만은 사실로 쓰지 않음 |

### 확신도 규칙 (`idea_council/confidence.py`)

검증자 모델은 증거만 모읍니다. 출처마다 등급(A/B/C), 운영 주체, 원출처, 1차 자료 여부, 이해관계를 적게 하고,
운영 주체나 원출처가 같은 출처는 하나로 묶어 독립 출처 수를 셉니다.

| 확신도 | 조건 |
| --- | --- |
| 90–99% | 독립 A등급 2개 이상 일치, 또는 1차 자료로 확인(경로 1), 또는 경로 2에 A등급 1개 추가 |
| 80–89% | 독립 출처 3곳 이상 일치, 반대 근거 없음(경로 2, 웹 교차 확인) |
| 60–79% | A등급 1개뿐이거나 독립 출처 2곳만 일치(조건부) |
| 40–59% | 독립성이 확인되지 않은 출처뿐이거나 결론이 혼재(미확정) |
| 40% 미만 | 반대 근거 우세 또는 근거 부족 |

80% 이상이 "검증 통과"입니다. 운영 주체와 원출처를 둘 다 적지 못한 출처(또는 "unknown", "?" 같은 자리표시)는 독립성을 보일 수 없으므로,
독립성이 확인된 출처가 하나도 없을 때만 한 묶음으로 세고(40–59%), 그 밖에는 개수에 더하지 않습니다.
지지와 반대가 동수면 혼재(40–59%), 반대가 더 많을 때만 반박됨(40% 미만)입니다.

웹 검색 도구는 모델에게 요약 조각만 주므로, 코드가 출처를 직접 확인합니다(`verify.py`).

- 페이지를 열어 인용 구절이 실제로 있는지 봅니다. 없거나, 인용이 비었거나, 404 등으로 열리지 않으면 뺍니다.
- 논문 주소(DOI, PubMed id, PMC id)는 OpenAlex에서 존재와 철회 여부를 확인하고, 없거나 철회된 논문은 뺍니다. 인용이 OpenAlex 초록에 있으면 페이지를 열지 않고 확인된 것으로 봅니다(제목만 인용한 것은 인정하지 않습니다).
- 같은 논문(같은 OpenAlex 작업·DOI·arXiv id, 또는 같은 제목)은 여러 사이트에서 찾았어도, arXiv 판과 학술지 판이어도 출처 하나로 셉니다. 원출처에 DOI·arXiv id(번호만 적어도 됨)를 적은 기사도 OpenAlex로 그 논문을 찾아 같은 출처로 셉니다.
- 이해관계 당사자의 1차 자료(공시·보도자료)는 독립 출처로 세지 않습니다. 그것만 있을 때는 코드가 "발표했다"와 "사실이다"를 구분할 수 없으므로 70%(조건부, 발표·공시 사실만 확인)로 두고, Notion 근거 요약에 판정 메모를 남깁니다.
- 숫자나 증가·감소·부정어만 다른 주장은 비슷해 보여도 합치지 않고 따로 검증합니다.
- 독립성이 확인된 출처가 1곳뿐이면 50%(미확정)입니다.
- 경로 2의 "A등급 1개 추가"는 독립 출처 3곳 중 하나가 A이면 충족으로 봅니다(A 1 + B 2 → 92%).
- PubMed·arXiv·출판사 같은 게재 플랫폼 이름은 운영 주체로 보지 않습니다(묶지도 않고, 독립성 확인으로도 치지 않습니다).
- 봇을 막는 페이지(401/403/429, 5xx, 시간 초과, 200이 아닌 2xx 응답, 캡차·쿠키 확인·iframe 껍데기 페이지)와 PDF는 남기되 "unchecked"로 표시합니다. 이런 출처는 지지·반대 각각 몇 개든 하나로만 세고, 인용을 확인한 출처가 하나도 없으면 통과하지 못하고 70%(조건부)에서 멈춥니다.
- 경로 2는 검증자가 반대 근거 검색어와 결과(`counter_search`)를 적었을 때만 통과합니다. 비었거나 "검색 안 함"이면 70%, 검증자가 반박을 찾았다고 표시(`rebuttal_found`)하면 50%입니다.
- stance는 support / contradict만 셉니다. neutral이나 알 수 없는 값은 버리고, refute·반대 같은 표현은 contradict로 읽습니다.
- 내부망·localhost 주소는 열지 않습니다. 리다이렉트마다 다시 확인하고, 호스트가 가리키는 IP가 모두 공인 주소여야 엽니다(확인과 접속 사이의 DNS 재바인딩까지 막지는 못합니다).
- OpenAlex가 응답하지 않으면 철회 여부를 확인하지 못했다고 표시합니다. `OPENALEX_API_KEY`가 있으면 함께 보냅니다.
- 설계 문서의 검증 절차와 달리 코드 버전은 Consensus를 부르지 않습니다. 학술 근거는 웹 검색 + OpenAlex 확인까지만 합니다.
- 남은 한계: 인용 구절이 페이지에 있다는 것은 확인하지만, 그 구절이 주장을 실제로 지지하는지는 검증자 모델의 판단에 기댑니다.

### 실행

```bash
uv venv && uv pip install -e '.[dev]'
export OPENROUTER_API_KEY=...
idea-council "이 아이디어의 가장 약한 고리는?" --context-file card.md --ideas-file ideas.txt
```

결과는 `runs/`에 markdown, JSON, Notion 행 payload(`*.notion.json`, 아이디어 허브의 주장·근거 DB와 연결 DB 속성 이름)로 저장됩니다.

환경 변수: `COUNCIL_MODELS`(쉼표 구분), `CHAIRMAN_MODEL`, `VERIFIER_MODEL`, `COUNCIL_ROLES`, `COUNCIL_ROTATE_ROLES=0`, `COUNCIL_MAX_CLAIMS`, `COUNCIL_SEED`.
기본 모델은 llm-council README와 같은 구성(OpenAI·Google·Anthropic·xAI 각 1개, 의장 Gemini)이되, README의 `gemini-3-pro-preview`와 `grok-4`가 OpenRouter에서 내려가 2026-11-04 기준 목록에 있는 id로 바꿨습니다.
모델 id는 자주 바뀌므로 실행 전에 OpenRouter 모델 목록과 대조하고, 없는 id가 있으면 바로 멈춥니다(`--skip-model-check`로 건너뜀).
웹 검색은 OpenRouter의 `openrouter:web_search` 서버 도구를 씁니다.

### 설계 근거

- 서로 다른 모델 계열로 된 판정단은 단일 대형 판정자보다 편향이 적습니다. [Verga et al., 2024](https://arxiv.org/abs/2404.18796)
- LLM 판정자에게는 위치·길이·자기 강화 편향이 있습니다. [Zheng et al., 2023](https://arxiv.org/abs/2306.05685), [Wang et al., 2024](https://aclanthology.org/2024.acl-long.511/)
- LLM은 자기 생성물을 알아보고 선호합니다. [Panickssery et al., 2024](https://doi.org/10.52202/079017-2197)
- 여러 에이전트의 상호 비판은 사실성을 높입니다. [Du et al., 2023](https://arxiv.org/abs/2305.14325)
